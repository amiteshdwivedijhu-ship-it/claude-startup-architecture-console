Messages API + tool use loop
One tool to start: search_tickets. The model calls the tool, we run it, the loop continues until the draft is ready. Keep the tool set small; every extra tool is a new failure mode.12
2
Prompt caching
Cache the system prompt and tool definitions with cache_control: ephemeral. Repeated tool-call turns skip re-processing the same prefix, which cuts cost and latency on multi-turn tickets.3
3
Context engineering
Compact ticket context: subject + last 3 messages, not the full thread. Pull KB articles by retrieval so the prompt stays small and the model answers from the right source.2
4
Human gate before deploy
Draft-only mode for week 1: every reply is approved by a human before it sends. Auto-reply ships later, only after its own eval set passes.5
